================================================================================
           ИНСТРУКЦИЯ ПО ПОЛУЧЕНИЮ OAUTH ТОКЕНА ДЛЯ «ДОМ С АЛИСОЙ PC»
================================================================================

Для работы приложения «Дом с Алисой PC» необходим персональный OAuth-токен 
Яндекса с правами на управление умным домом.

Токен создаётся один раз через официальный портал Яндекс OAuth и привязывается 
к вашему личному аккаунту Яндекс. Токен сохраняется исключительно на вашем ПК 
и никогда не передаётся третьим лицам.

--------------------------------------------------------------------------------
ШАГ 1. Создание приложения в Яндекс OAuth
--------------------------------------------------------------------------------
1. Откройте любой браузер и перейдите на официальный сайт Яндекс OAuth:
   https://oauth.yandex.ru/

2. Убедитесь, что вы вошли в тот Яндекс-аккаунт, к которому привязан ваш умный дом!

3. Нажмите кнопку «Создать приложение» (или сразу перейдите по ссылке):
   https://oauth.yandex.ru/client/new

4. Заполните поля приложения:
   - «Название приложения»: укажите любое удобное название, например:
     Дом с Алисой PC

   - «Платформы»: выберите пункт «Веб-сервисы».

   - «Callback URL» (Redirect URI): нажмите «Подставить verification_code» 
     или вручную введите:
     https://oauth.yandex.ru/verification_code

5. Настройка доступов (Скоупы / Scopes):
   В разделе «Доступы» найдите блок «Умный дом» (или введите в строке поиска «iot»):
   - Отметьте галочкой: iot:view (Просмотр состояния умного дома)
   - Отметьте галочкой: iot:control (Управление устройствами и сценариями)

6. Нажмите кнопку «Создать приложение» в самом низу страницы.

--------------------------------------------------------------------------------
ШАГ 2. Получение OAuth-токена
--------------------------------------------------------------------------------
После создания приложения вы окажетесь на его странице.

1. Найдите строку «ClientID» (набор латинских букв и цифр) и скопируйте его.

2. Сформируйте ссылку для получения токена:
   https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID

   (Замените «ВАШ_CLIENT_ID» в конце ссылки на скопированный ClientID вашего приложения).

3. Вставьте получившуюся ссылку в адресную строку браузера и перейдите по ней.

4. Нажмите желтую кнопку «Войти как ...» / «Разрешить доступ».

5. Яндекс перенаправит вас на страницу с сообщением об успешной авторизации.
   В АДРЕСНОЙ СТРОКЕ браузера появится длинная ссылка вида:
   https://oauth.yandex.ru/verification_code#access_token=y0_AgAAAA...&token_type=bearer...

6. Скопируйте всё значение токена после «access_token=» и до знака «&» 
   (токен обычно начинается с символов «y0_»).

--------------------------------------------------------------------------------
ШАГ 3. Подключение в приложении «Дом с Алисой PC»
--------------------------------------------------------------------------------
1. Запустите приложение «Дом с Алисой PC».
2. В левом нижнем углу нажмите кнопку «Настройки» (иконка шестерёнки).
3. Во вкладке «OAuth Токен» вставьте скопированный токен в поле ввода.
4. Нажмите кнопку «Сохранить и загрузить дом».

Поздравляем! Ваши комнаты, умные устройства, датчики и сценарии загрузятся 
и будут доступны для управления прямо с вашего компьютера.

--------------------------------------------------------------------------------
БЫСТРЫЙ ВХОД ЧЕРЕЗ ВКЛАДКУ «CLIENT ID» (АЛЬТЕРНАТИВА)
--------------------------------------------------------------------------------
Вместо ручного копирования ссылки из шага 2 вы можете просто открыть 
в Настройках приложения вкладку «Client ID», вставить скопированный ClientID 
и нажать кнопку «Открыть окно авторизации». Приложение само откроет окно входа 
и автоматически получит токен.
