# Дом с Алисой PC 🏠⚡

**«Дом с Алисой PC»** — удобное, быстрое и современное настольное приложение для Windows для полного контроля над вашим Умным домом Яндекса прямо с компьютера.

**created by smokelnk**

---

## ✨ Основные возможности

- 💡 **Управление устройствами в один клик**:
  - Мгновенное включение и выключение розеток, выключателей, ламп и реле.
  - Настройка яркости и цветовой температуры для умных ламп.
  - Датчики, умные колонки, хабы и пульты — отображают статус **В сети / Не в сети**.
  - Управляемые устройства (свет, розетки, увлажнители, телевизоры) — отображают **Включено / Выключено**.
- 📂 **Организация по комнатам**:
  - Быстрое переключение между комнатами дома.
  - **Drag & Drop**: перетаскивайте вкладки комнат мышью или используйте кнопки со стрелками, чтобы расставить важные комнаты первыми.
  - Закрепленная вкладка «Все устройства».
- ⚡ **Сценарии Яндекса**:
  - Просмотр подробных настроек сценария: условия срабатывания и перечень действий с точными названиями устройств и комнат.
  - Запуск сценариев отдельной кнопкой «Play» в один клик.
  - Отображение статуса отключённых сценариев.
- 🌡️ **Показатели датчиков на русском языке**:
  - Температура (°C), влажность (%), CO₂ (ppm), давление (мм рт. ст.), мощность (Вт), напряжение (В).
  - Состояние открытия дверей и окон, заряд батареи.
- 📜 **История событий датчиков**:
  - Подробный журнал с точным временем событий.
  - Умные кнопки: тип нажатия (**одинарное**, **двойное**, **длинное удержание**).
  - Датчики открытия, протечки воды, движения, вибрации.
  - Фильтрация по типу события и поиск по имени устройства / комнаты.
- 🎨 **Темы оформления**: фирменная тёмная и полностью чёрно-белая монохромная тема.
- 🔔 **Уведомления**: понятные всплывающие сообщения об успехе и ошибках.

## 🚀 Установка

1. Скачайте установщик: `Home with Alice PC Setup 1.0.0.exe`
2. Запустите установщик и следуйте инструкциям мастера.
3. После установки запустите приложение с рабочего стола или из меню «Пуск».
4. Откройте **Настройки** (шестерёнка в левом нижнем углу) и введите OAuth-токен.
5. Готово — все ваши устройства и сценарии загрузятся автоматически!

> Никаких дополнительных программ устанавливать не нужно. Всё включено в установщик.

## 🔑 Как получить OAuth-токен Яндекса

Подробная пошаговая инструкция также продублирована в файле **`readme.txt`** в корне проекта и открывается прямо из настроек приложения.

### Создание собственного приложения в Яндекс ID:

1. Перейдите на [oauth.yandex.ru](https://oauth.yandex.ru/) и нажмите **«Создать приложение»**.
2. Укажите любое название, например: `Мой умный дом PC`.
3. В разделе **«Платформы»** выберите **«Веб-сервисы»** и в поле **Callback URL** добавьте:
   ```
   https://oauth.yandex.ru/verification_code
   ```
4. В разделе **«Доступы»** найдите и отметьте:
   - `iot:view` — просмотр состояния умного дома
   - `iot:control` — управление устройствами и сценариями
5. Сохраните приложение и скопируйте **Client ID**.
6. Откройте в браузере (вы должны быть авторизованы в нужном аккаунте Яндекса):
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
   ```
7. Нажмите **«Разрешить»** и скопируйте токен из адресной строки (часть после `access_token=`, до `&`).
8. Вставьте токен в **Настройки** приложения → «Сохранить токен».

## ⚖️ Безопасность

- OAuth-токен хранится **только локально** в вашей системе и никогда не передаётся сторонним серверам.
- Все запросы идут напрямую к официальному API Яндекса (`https://api.iot.yandex.net/v1.0/`).
